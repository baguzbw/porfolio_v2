# Company logos

Drop your logo files here using these exact names — the About page career
cards already point at these paths, so nothing else needs to change:

- `ifars.png` — PT IFARS Pharmaceutical Laboratories
- `star-software.png` — PT STAR Software Indonesia
- `sims-life-media.png` — PT SIMS Life Media
- `inco-academy.png` — INCO Academy
- `telkom-university.png` — Telkom University
- `uns.png` — Universitas Sebelas Maret (UNS)
- `smkn-2-surakarta.png` — SMK Negeri 2 Surakarta

Any square-ish image works (PNG with transparent background looks best).
Until a file exists, the card automatically falls back to showing the
company's initials instead — nothing breaks if you leave one out.

To change the filename or add another job, edit `logoSrc` in
`data/profile.ts`.
